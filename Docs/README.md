# LongV 短剧导演台

一个本地运行的原型：输入一句故事，建立剧本、角色、环境、分镜、视频和合成六步项目；每一步可单独重跑，视频阶段可按镜头批量调用本地 ComfyUI。

## 启动

```powershell
cd D:\Demo\kitt\LongV
npm start
```

打开 http://127.0.0.1:3030。

## 接入 ComfyUI

1. 先启动 ComfyUI API，默认地址是 `http://127.0.0.1:8188`。
2. 在网站右上角打开“连接设置”。
3. 导入 ComfyUI 的 **API 格式** workflow JSON（不是拖到画布用的普通 JSON）。
4. 填写正向提示词节点 ID 和字段名，例如节点 `42`、字段 `text`。
5. 如果工作流使用占位符，也可以在 API JSON 的输入值里使用 `{{prompt}}`、`{{width}}`、`{{height}}`、`{{frames}}`。

现在支持在前台保存多个工作流并按阶段绑定：例如“AI编剧”绑定到剧本，“SDXL环境图”绑定到环境，“H3图生视频”绑定到视频。打开右上角“连接设置”，填写工作流名称、选择阶段、导入对应的 API JSON，再保存即可；上方每个阶段的下拉框可以切换已保存的工作流。

导入 workflow JSON 后，网站会自动扫描节点并提供下拉选择，不需要手动填写节点 ID。它会识别文本节点、LoadImage 节点和可用字段；切换已保存的工作流时也会重新加载对应节点。

工作流绑定和 ComfyUI 地址按项目保存。切换项目后，连接设置会显示该项目自己的配置；左侧项目列表支持右键删除，删除时会同时删除项目 JSON 和该项目的生成文件。

项目会提交 `/prompt`，轮询 `/history/{prompt_id}`，然后从 `/view` 下载输出到 `data/projects/<project>/<stage>/`。

阶段资产会自动传递：分镜阶段优先使用环境阶段的图片，视频阶段优先使用分镜阶段的图片。服务器会先调用 ComfyUI `/upload/image`，再把返回的文件名写入绑定工作流的图片节点；因此需要为分镜和视频工作流填写 `输入图片节点 ID`。

## 当前边界

剧本阶段使用本地模板拆分镜头；真正的角色图、环境图、分镜图和视频需要你导入对应的 ComfyUI API 工作流。由于不同 H3 工作流的节点 ID、提示词节点和输出节点都不一样，项目把这些映射保留为设置，而不是猜一个不可用的固定 JSON。
